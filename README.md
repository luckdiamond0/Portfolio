# Portfolio Website

## Overview
This is a modern, responsive portfolio website built with React and Vite. It showcases my skills, projects, and contact information with a clean, professional design featuring interactive elements and smooth animations.

## Features
- **Interactive Code Display**: A visually appealing code snippet with 3D tilt effect that introduces me as a developer
- **Skills Section**: Visual representation of my technical skills with progress indicators
- **Projects Showcase**: Gallery of my projects with descriptions, technologies used, and links to repositories
- **Contact Section**: Easy ways to get in touch via email and social media
- **Responsive Design**: Fully responsive layout that works on all device sizes
- **Animations**: Smooth animations and transitions using Framer Motion

## Technologies Used
- **React**: Frontend library for building the user interface
- **Vite**: Next generation frontend tooling for faster development
- **Framer Motion**: Animation library for React
- **React Icons**: Icon library for social media and UI elements
- **CSS**: Custom styling with responsive design principles

## Projects Featured
1. **Login App**: A login application with a backend built with C#, JavaScript and ImGui
2. **Charm Pad**: Notepad for productivity enhancement built with C# and WPF
3. **Charm Tool**: Multitool created in C# designed for ease and agility

## Setup and Installation

```bash
# Clone the repository
git clone https://github.com/luckdiamond0/portfolio.git

# Navigate to the project directory
cd portfolio

# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build
```
